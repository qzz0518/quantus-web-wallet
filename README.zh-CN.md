# Quantus Web Wallet

[打开钱包](https://qtc.zezn.dev) · [English](README.md) | 简体中文

Quantus 网络的网页钱包。密钥只留在你的设备上，没有服务器、没有手续费，可以作为 PWA 安装到手机和电脑。

## 功能

- **账户。** 创建、导入和管理多个钱包。支持网络使用的两种签名方案：ML-DSA-65（官方钱包默认，路径 `m/44'/189189'/n'/0'/1'`）和 ML-DSA-87（`…/0'/0'`）。导入时先显示派生地址，与官方钱包核对一致后再保存。观察账户（含 Wormhole 地址）显示公开余额与入账。余额下方显示按 SafeTrade QUANTUS/USDT 行情（最新成交价，没有成交时取买卖中间价）折算的美元估值（USDT 按美元计），悬停可见单价。切换钱包时顶部显示所有有公开余额的账户的总资产（QTC 与美元），每个钱包右侧是自己的数字；加密账户和类型待确认的账户照常列出但不计入总额，某个余额还没读到时宁可不显示总额，也不显示偏低的数字。
- **转账。** 发送 QTC、二维码收款，跟踪每笔交易从提交到最终确认。输入金额前钱包会在公开索引器上核对收款地址：只收到过挖矿奖励、从未发出过交易的地址几乎可以确定是加密账户（Wormhole），钱包会说明后果并要求确认；没有链上记录的地址会给出提醒。
- **可撤回的延时转账。** 在填金额那一步可以把「立即到账」换成「延时到账，可撤回」，并选择链上要等多久——10 分钟、1 小时、1 天（运行时自己的默认值 7200 块），或者自己填区块数。在那之前这笔金额冻结在你的账户上；预览页会写明预计在第几块、大约什么时候到账；所有还在等的转账显示在活动记录上方，带进度和「撤回」按钮。撤回后资金退回本账户，链上不对撤回收费，只有撤回交易本身的网络手续费。每个账户最多 16 笔待到账（运行时的上限）；观察账户能看到列表，但不能撤回。
- **校验短语。** 每个地址还对应五个词，用的是 Quantus 官方的校验短语算法（[qp-human-checkphrase](https://github.com/Quantus-Network/qp-human-checkphrase)，MIT）。收款页、钱包详情和转账的收款人步骤都会显示：双方读五个词，比核对五十个字符可靠——地址差一个字符，短语就完全不同，这正是防住相似地址的地方。短语用 PBKDF2 在你的浏览器里算出来，不会发往任何地方。
- **记录。** 转入、转出和挖矿奖励，支持搜索和筛选，可跳转 Quantus 区块浏览器。
- **备份与安全。** 钱包用至少 6 位的密码在本地加密；可导出和恢复加密备份；助记词可下载，并通过候选词选择验证备份。支持 WebAuthn PRF 的浏览器可用设备指纹、人脸或锁屏解锁。闲置 10 分钟自动锁定。
- **免密模式。** 在私人电脑上可在设置中开启：验证一次密码后，每次打开页面钱包自动解锁，不再闲置锁定；手动锁定会保持到下次打开页面。解锁密钥由保存在本浏览器里的不可导出密钥封装，任何能打开这台电脑上这个浏览器的人都能打开钱包。设备解锁和密码仍然可用；修改密码或恢复备份后该模式自动关闭。
- **加密账户（Wormhole）。** 工具里分两个标签。「存入」从你自己某个钱包的助记词派生一个从未收过款的收款地址——复用已经收过款的地址会把两笔支付在公开视图里连起来——并显示二维码、校验短语，以及以后取回要付出的代价。「扫描与取回」用官方钱包的助记词扫描其加密账户，查看真实的未花费余额，并把入账取回到普通账户。见[下文](#加密账户恢复)。
- **挖矿计算。** 在「工具」中。页面开头就是决定一台矿机的四个数字——每天期望产量、每天利润、保本价、保本租金——并在你调整输入时始终可见。先选显卡（或直接填总算力）、数量和矿工软件；在线率、矿池和矿工软件费率、电价或整机租金、可选的设备成本和货币标签收在「更多设置」里；难度上涨敏感性、显卡对比、网络状态和计算方法都是折叠的，需要时再展开。保本租金——一台机器每小时、每天最多花多少钱租还能保本——会出现在每张显卡下面、整机结果里，以及显卡对比表的一列：等于每天产量按 QTC 价格折算的产值，减去租金没有包含的运行成本（整机租用已含电费，所以就是全部产值；自有设备先减掉电费）。难度和实测出块时间来自链上 RPC，最近的区块奖励来自公开索引器，显卡基准、费率和实测运气来自 Quanpool 公开接口（读取失败时使用内置快照），矿池未测过的显卡用矿场实测算力补齐，QTC 价格来自 SafeTrade 的公开 QUANTUS/USDT 行情（最新成交价，没有成交时取买卖中间价）——这次请求会让交易所看到你的 IP，且交易所会挡掉一部分访问者；无论成功与否，你都可以自己填一个价格，页面就按你填的算。所有数字都是期望值，输入只保存在你的浏览器里。
- **界面。** 中英文（首次跟随浏览器语言，设置中可切换）、浅色 / 深色 / 跟随系统主题、手机与桌面布局、可安装为 PWA 并离线启动。

## 安全模型

- 助记词和密钥只存在这个浏览器里，用你的密码加密。派生和签名在一次性的 Web Worker 中由内置的 Rust/WASM 模块完成；助记词不会明文写入存储，不会上传，也不会交给任何服务器。
- 钱包页面只连接官方 Quantus RPC 节点和索引器，另外每分钟读取一次 SafeTrade 的公开 QUANTUS/USDT 行情来折算余额的美元估值；挖矿计算还会读取 Quanpool 公开接口，其他页面不会。随站点下发的内容安全策略不允许连接别的地址。没有遥测、没有统计脚本、没有服务费。
- 签名钉死在主网 runtime（`specVersion` 152、`transactionVersion` 6）。网络升级后钱包会拒绝签名，直到经过核对并更新。
- 部署可以校验：`node scripts/verify-deployment.mjs` 会逐个比对线上文件与本地构建，并检查安全响应头。
- 本项目未经独立安全审计。请把助记词备份在浏览器之外。

## 加密账户恢复

**是什么。** 官方 Quantus 钱包带有「加密账户」（Wormhole）。它的地址看起来和普通地址一样，但由助记词按 `m/44'/189189189'/0'/<branch>'/<index>'` 派生。每一笔转入这种地址的资产都会成为隐私池中的一条入账，只有持有助记词的人才能分辨哪些入账尚未花费，观察账户只能显示「未知」。不少用户误把资产转到了这类地址上。

**存入自己的隐私账户。** 「存入」标签扫描你已有钱包的收款分支，找到第一个从未收过款的索引，显示这个地址的二维码和校验短语。旁边的费率和 0.01 QTC 取整粒度都是从链上读的，不写死。转进去的资产只有持这份助记词的人能取出来。

**工具做什么。** 在 *设置 → 工具 → 加密账户恢复* 中，可以用官方钱包的助记词扫描加密账户。扫描是只读的：在一次性的本地组件中派生收款与找零地址，向官方索引器查询这些地址的入账，在本地计算每条入账的花费凭证（nullifier），再向官方节点核对是否已花费。未花费的入账可以取回到普通账户：零知识证明在浏览器中生成、本地验证通过后只提交一次。

**步骤。**

1. 打开 *设置 → 工具 → 加密账户恢复*，阅读说明。
2. 输入官方钱包的 24 个助记词单词。可选：粘贴官方钱包显示的加密账户地址，结果会告诉你它是否在派生地址之中。
3. 勾选网络查询提示后开始扫描。进度页显示阶段、分支、已扫描地址数和已找到的入账数，随时可以取消。
4. 查看结果：可取回余额、已花费入账、快照区块，以及可勾选的未花费入账列表。
5. 最多选择 7 条入账，选择收款账户（本钱包中的签名账户，或从同一助记词派生的普通账户），核对费用预览后提交。回执显示交易哈希、状态和区块浏览器链接；此前的回执会列在工具首页。

**费用。** 链上按取回金额收取 0.04% 的成交量费用。金额先向下取整到 0.01 QTC，每笔入账不足 0.01 QTC 的零头会丢失。费用一半销毁、一半归出块矿工，没有返还。生成证明需要约 1.5 GB 内存和一分钟左右，请使用桌面浏览器并保持页面打开。

**限制。** 扫描固定在节点与索引器一致的某个最终确认区块，之后的入账不会包含在内。每个分支在连续 20 个未使用地址后停止；当账户超过每分支 1000 个地址或总计 10000 条入账时会拒绝给出余额，把不完整的扫描显示为错误而不是偏小的余额。一次取回最多 7 条入账，入账更多的账户需要分多次取回。单笔不足 0.02 QTC 的入账无法单独取回，费用会把它吃掉。助记词只留在页面与本地签名组件中，但官方索引器与节点会看到派生出的地址和你的 IP 地址。

## 安装

打开[网页钱包](https://qtc.zezn.dev)，在浏览器中选择 **安装应用** 或 **添加到主屏幕**。iPhone 请使用 Safari → 分享 → 添加到主屏幕。余额更新与转账需要联网。

## 开发

需要 [Bun](https://bun.sh) 1.4.0。也可通过 [mise](https://mise.jdx.dev) 运行 `mise install` 安装项目固定版本的工具。

```sh
git clone https://github.com/qzz0518/quantus-web-wallet.git
cd quantus-web-wallet
bun install --frozen-lockfile
bun run dev        # http://127.0.0.1:5189
bun run check      # TypeScript 检查
bun run test       # 单元测试，含英文字典完整性检查
bun run build && bun run preview
```

布局检查用的浏览器夹具在 `tests/browser/`。取回的端到端测试只针对隔离的本地开发链运行，且需要设置 `QUANTUS_DEV_TEST=1`。签名模块和 Wormhole 证明器以编译好的 WASM 形式随仓库提供，只有[重新编译](vendor/PROVENANCE.md#rebuild)时才需要 Rust（`scripts/build-wasm.sh`、`scripts/build-prover.sh`）。

## 部署

将 `dist/` 部署到启用 HTTPS 的静态托管服务。`_headers` 文件包含内容安全策略、HSTS 等安全响应头，支持该文件的托管平台会自动应用；`wrangler.jsonc` 是 qtc.zezn.dev 使用的 Cloudflare 部署配置（`bun run deploy`）。部署后运行 `node scripts/verify-deployment.mjs [站点地址]`，确认线上文件与本地构建一致并检查响应头。
